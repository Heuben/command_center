## Getting Started

1. Run `npm install`
2. Run `npm run dev` to start the API and web app together.

The login page's **Enter system (development only)** button creates a local
development session for the active superadmin or admin account. It is available
only in the Vite development build and the API development mode; it is not
available in production. The Vite development server proxies `/api` requests to
the local API on port `8787`. You can also run the API alone with
`npm run dev:api` when needed.

## Live dispatch

Live dispatch controls are disabled. The dashboard retains links and summary counts for incident
records, reports, personnel, and audit history. Existing incident and dispatch history remains
available for review.
